🖼️ Getting Azure icons in draw.io

✅ Icons are now embedded as real PNG URLs — no library setup needed
  1. Generate your diagram → Click ⚡ Open in draw.io or ⬇ Download .drawio
  2. For Open in draw.io: click Extras → Edit Diagram, paste XML → OK
  3. Icons load automatically from GitHub CDN (internet required) ✓
🔧 If icons still don't appear (offline / corporate proxy)
  1. Download the .drawio file
  2. Open draw.io → View → Shapes → Azure 2 → enable
  3. Re-import the file — icons render from the local stencil library ✓
